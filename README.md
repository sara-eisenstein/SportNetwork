# SportNetwork 🏋️‍♀️

**SportNetwork** היא רשת חברתית בתחום הספורט, שמאפשרת למשתמשים ליצור פרופילים, לנהל צ'אטים פרטיים, לשתף תכנים ולעקוב אחרי משתמשים אחרים. המערכת כוללת גם ניהול אירועים, תיעוד פעילות, ואפשרויות מתקדמות לתקשורת בין ספורטאים.

---

## ✨ תכונות עיקריות

- 🔒 מערכת הרשמה והתחברות מאובטחת עם JWT
- 🗨️ צ'אט בזמן אמת בין משתמשים עם WebSocket
- 📅 יצירה וניהול של אירועים ספורטיביים
- 📂 ניהול קבצים ומסמכים לאירועים
- 📈 פגינציה של הודעות, רשימות משתמשים ועוד

---

## 🛠 טכנולוגיות בשימוש

**Frontend**:
- React
- TypeScript
- Redux Toolkit
- Tailwind CSS / CSS Modules

**Backend**:
- ASP.NET Core Web API
- C#
- Entity Framework Core
- SignalR (לצ'אט)

**Database**:
- SQL Server / SQLite

---
